# Nefesh

Игровой портал: форум, аукцион, база знаний и калькулятор персонажа.

**Сайт:** https://snowganter.github.io/nefesh/

## Возможности и хранение

Это статическая демонстрация. Игровая база входит в сборку. Профили, публикации, лоты и изменения администратора сохраняются в localStorage и IndexedDB конкретного браузера. Между посетителями и устройствами данные не синхронизируются. Вход `admin / admin` открывает локальную демонстрационную админку.

Для пробного профиля используйте отдельный тестовый пароль. Для настоящего сообщества потребуется отдельный сервер с авторизацией и общей базой данных; GitHub Pages обслуживает статические файлы.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для проверки итоговой статической сборки:

```sh
npm run build
npm start
```

## Проверки

```sh
npm test
npm run typecheck
npm run lint
npm audit --omit=dev
```

В tests проверяются безопасное вычисление формул и обмен билдами. Ядро приложения написано на TypeScript; унаследованные компоненты страниц — на JavaScript/JSX. Проверка TypeScript не охватывает всю логику JavaScript. Ошибки типов ядра останавливают production-сборку.

## Публикация

Workflow `.github/workflows/pages.yml` собирает и публикует сайт при изменениях в main. В Settings → Pages выбран источник GitHub Actions. Для проекта nefesh путь ресурсов — `/nefesh`.

Для локальной сборки с таким же путём в PowerShell:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = '/nefesh'
npm run build
npm start
```

## Данные и исходники

- src/data — предметы, способности, NPC и начальные демонстрационные данные.
- src/lib — хранилища, маршрутизация и игровые расчёты.
- src/components/pages — разделы портала.
- src/app — оболочка и статическая страница скачивания исходников.

Ссылки вида `#!/forum/topic/…` поддерживают переходы и обновление страницы на статическом хостинге. Кнопка обмена билдом открывает калькулятор с выбранной сборкой, включая позиции аксессуаров и способностей. Просмотр чужой ссылки не перезаписывает сохранённый профиль; для этого используется кнопка «Сохранить».
